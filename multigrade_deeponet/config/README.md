# Selected pendulum configuration

The configuration, comparison protocol, and recorded metrics for the selected
parameter-matched run are in [`../../evidence/pendulum_protocol.json`](../../evidence/pendulum_protocol.json)
and [`../../evidence/pendulum_summary.json`](../../evidence/pendulum_summary.json).
They are stored once in the root evidence directory to avoid duplicate copies.
